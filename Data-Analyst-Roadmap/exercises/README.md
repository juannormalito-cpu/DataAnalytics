# Exercises

One folder per chapter, each following the same five-tier structure:

```
exercises/<chapter>/
├── warmup/        # quick recall checks, 5-10 min each
├── practice/       # applied problems matching chapter examples
├── challenge/       # harder, multi-concept problems
├── mini_project/     # small end-to-end task tying the chapter together
└── solutions/       # worked solutions for everything above
```

Populated as each corresponding chapter in [`../handbook/`](../handbook/) is written.
