# Datasets

One folder per chapter. Each dataset gets a brief (`<dataset_name>.md`) with:

- **Difficulty**
- **Description**
- **Business Context**
- **Skills Learned**
- **Expected Deliverables**
- **Questions to Answer**
- **Estimated Time**
- **Link** (preferring Kaggle)

Populated as each corresponding chapter in [`../handbook/`](../handbook/) is written. See [`../notion/06_Dataset_Database.md`](../notion/06_Dataset_Database.md) for the Notion-side index.

**Full catalog:** [`CATALOG.md`](CATALOG.md) — every dataset used across the handbook, organized by chapter (Adventure Works, Northwind, Titanic, House Prices, Global Superstore, Instacart, Google Play Store, Customer Churn, Rossmann, Credit Card Fraud, Steam, Spotify, Formula 1, Airbnb, Netflix, Amazon Reviews).
