# Adventure Works

- **Difficulty:** Beginner–Intermediate
- **Description:** Microsoft's classic sample OLTP database for a bicycle manufacturer — sales, production, HR, purchasing.
- **Business Context:** Used company-wide as the reference schema for learning relational design, normalization, and Star Schema conversion (see [Chapter 03](../../handbook/03_Databases.md)).
- **Skills Learned:** ERD reading, normalization, star-schema remodeling, multi-table SQL joins.
- **Expected Deliverables:** A hand-drawn (or Mermaid) star schema derived from the OLTP source; a SQL script building `fact_sales` + dimensions from it.
- **Questions to Answer:** Which product categories drive the most revenue? Which sales territories are underperforming relative to headcount?
- **Estimated Time:** 4–6 hours
- **Link:** https://www.kaggle.com/datasets/ukveteran/adventure-works
