# Portfolio Projects

Ten full, company-style projects. Each project folder follows the same structure:

```
projects/<NN_Project_Name>/
├── README.md        # business problem, objectives, architecture, workflow, conclusions
├── data/           # raw/processed data or links to source
├── sql/            # schema + queries
├── python/          # cleaning, EDA, feature engineering, modeling
├── powerbi/          # .pbix or exported dashboard assets
├── diagrams/         # DB diagram, architecture diagram, workflow diagram
└── presentation/       # executive summary / slide deck
```
