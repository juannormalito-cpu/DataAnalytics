# Printable PDF

The compiled, printable version of the handbook: professional cover, table of contents, page numbers, headers/footers, consistent typography.

Generated by [`build_pdf.py`](build_pdf.py), which concatenates all 9 chapters from [`../handbook/`](../handbook/) into one document with a cover page, table of contents, running headers/footers, and print typography.

## Rebuild after any chapter edit

```bash
pip install markdown
python pdf/build_pdf.py            # English, from /handbook
python pdf/build_pdf.py --lang es  # Spanish, from /handbook_es
```

Produces the `.html` always, and `.pdf` via (in order of preference): WeasyPrint if its system libraries are installed, headless Microsoft Edge/Chrome if found, or — as a zero-install fallback — open the generated `.html` in any browser and use *File → Print → Save as PDF*.
