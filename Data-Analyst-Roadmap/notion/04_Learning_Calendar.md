# 📅 Learning Calendar

> Sub-page of [🏠 Home](00_Home.md). In Notion, recreate this as a **Calendar database view** with a `Track` select property (6-month / 12-month / 18-month) so you can filter to the track you're following.

## Tracks Overview
| Track | Pace | Best for |
|---|---|---|
| 6 months | Intensive, ~25–30 hrs/week | Career switchers studying full-time |
| 12 months | Balanced, ~12–15 hrs/week | Working professionals with evenings/weekends free |
| 18 months | Sustainable, ~6–8 hrs/week | Full-time job/studies, part-time learning |

## Weekly Schedule Template
| Day | Focus block |
|---|---|
| Mon | New concept (reading + notes) |
| Tue | Hands-on exercises |
| Wed | New concept (reading + notes) |
| Thu | Hands-on exercises |
| Fri | Mini-project work |
| Sat | Project work / review |
| Sun | Rest or light review |

## Daily Schedule Template (intensive track)
| Time block | Activity |
|---|---|
| Deep work #1 (90 min) | New material, no distractions |
| Practice (60 min) | Exercises tied to the day's material |
| Break | — |
| Deep work #2 (90 min) | Project or portfolio work |
| Review (30 min) | Notes, flashcards, recap |
